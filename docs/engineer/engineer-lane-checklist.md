# THE ENGINEER LANE — RUNG CHECKLIST
*Segments E0–E3. Conventions as in the repo: every rung ships with predictions filed before first run, a null that must refuse, an explicit refusal path, and receipts. Nothing composes unless its parts are UNDERSTOOD. Dates and results get appended per rung as they land.*

---

## E0 — SHARED FOUNDATIONS (before any domain; most of this is one evening)

**E0.1 — The kinds rung (structural vocabulary).**
Structural primitives (plane, thread, surface, tube…) as atoms; typed relation doors (grown-from, wrapped-around, extruded, repeated-along). Court: a proposed composite must account for planted composed data better than its ingredients separately, past a scrambled null.

**E0.2 — Multi-view identity.**
One identity, N decompositions (tube = hollow cylinder = extrusion = faces). Court: where views overlap in consequences, answers agree machine-exact. Null: two views of *different* things forced under one identity → disagreement detected, routed as a wound.

**E0.3 — Slot signatures.**
Every operation/part declares inputs, outputs, and residue as official slots (division is two-in two-out). Court: presence + type + balance; an unaccounted in or unclaimed out is a named violation. This court is reused verbatim by all three domains.

**E0.4 — Dependency propagation (the TMS rung).**
Dependencies typed fixed (.002") or relative (.5%). Change one value → propagate → re-verify all → divergence flagged with size and direction. Null: an over-constrained inconsistent set refuses with the residual named.

*Gate E0: all four courts green on toys. These four are the whole lane's grammar; every later rung is these courts wearing domain costume.*

## E1 — CODE & LOGIC (start here)

**C1 — Read → map.**
Small program in; flowchart (control flow) + data flow out, as doors. Court: every statement, branch, and variable appears in the map exactly once; map + values regenerate the program's structure. Null: a scrambled program yields a measurably different map.

**C2 — The containment court.**
Input-space accounting with three verdicts: CONTAINED (every input in region provably reaches defined handling — receipt), UNCONTAINED (escaping input named, path shown), REFUSED (region beyond current vocabulary — eval/reflection — parked, never silently passed). Probe: toy with three planted uncontained edge cases — all three found; fully-contained toy — proven contained. Null: the tool must not claim containment on the planted-holes toy.

**C3 — Intent triangulation.**
Three witnesses: docs (promised), code-majority (practiced), data (actual flow). Planted deviant among five similar handlers — classified deliberate special-case vs bug vs rot by correlation character (the till-theft organ, re-aimed). Docs are a witness, never ground truth. Null: a deviant correlating with nothing must not be called deliberate.

**C4 — Shape mining on code.**
Recurring patterns (validation shape, error-handling shape, retry shape) minted as composites via the genesis loop; minted shapes offered forward as vocabulary. Court: minted shape re-found in unseen code; scrambled code refuses the match.

**C5 — Construction closes the loop.**
Uncontained region + vocabulary shape → synthesize the patch → render code → **re-read with the same C2 court** → hole proven closed. Null: a deliberately broken synthesis must fail its own court. (Generation eats its own verification; no exceptions.)

**C6 — The rebuild gauntlet.**
Small spaghetti program → map → rebuild from the map, behavior-identical, plus a divergence ledger ("original does X in these 3 places; intent evidence says Y; choose per item"). Load-bearing bug preserved and *flagged*, not silently fixed (Chesterton's fence). Court: original vs rebuild agree on a frozen probe set everywhere outside the ledger.

*Gate E1: C1–C6 green. Deliverable exists: map + verdicts + rebuild with ledger — this is already the legacy-remediation product in miniature.*

## E2 — MECHANICAL

**M1 — The tube court.**
ID/OD/wall/schedule: any two derive the third; all three consistent = corroboration receipt; inconsistent = refusal with constraint residual named; one given = named DOF, never a guessed shape.

**M2 — Handbook ingestion.**
Fits, clearances, thread tables, schedules as told-knowledge with open citations (pre-corroborated vocabulary; a century of machinist consensus enters as structure, provenance attached).

**M3 — Mates as typed doors.**
Concentric, coincident, distance, ratio (gear), cam-follower. Court: assembled toy mechanism is kinematically consistent; an impossible mate set refuses.

**M4 — Propagation on a part stack.**
Bore +.010 → ledger of every affected dimension via typed dependencies; tolerance stack-up computed along door chains with receipts; the one clearance that no longer clears is named. (This rung alone is a sellable report.)

**M5 — Kinematics as lawform walking.**
Slider-crank position/velocity from the mate structure, stepped in time; court: agreement with closed form to machine precision.

**M6 — The engine gate.**
Multi-part assembly (start: single-cylinder, not V8) from vocabulary + mates + dependencies; geometry kernel (FreeCAD/OpenCascade) used as instrument, never mind — Isaac's derived masses/interferences vs kernel's computed ones; divergence = wound. The V8 is M6 with bigger counts, run when M6 is boring.

*Gate E2: a parametric mechanism that rebuilds correctly under dimension changes, with stack-up receipts.*

## E3 — ELECTRICAL

**EL1 — Conservation courts.**
Kirchhoff current (node) and voltage (loop) as slot-balance courts; toy resistor networks machine-exact; an unbalanced net refuses with the residual named.

**EL2 — Datasheets as slot signatures.**
Components ingested as typed slots + limits (a datasheet is a slot signature in PDF form); vocabulary with citations.

**EL3 — SPICE as instrument.**
Isaac derives the operating point; SPICE computes it; agreement = receipt, divergence = wound. Instrument, never mind — same doctrine as the geometry kernel and ollama.

**EL4 — Planted-fault forensics.**
Circuit with one wrong resistor / one cold joint modeled — located by residual accounting; character named (wrong value vs wrong topology). This is the shadow organ with a soldering iron.

**EL5 — Synthesis.**
Small spec (divider with load, RC filter at f) → circuit assembled from vocabulary → EL3 court passes. Construction as proof, third substrate.

*Gate E3: spec → verified circuit, with every claim carrying either a conservation receipt or a SPICE cross-check.*

## STANDING RULES (all segments)

1. Predictions filed before first run, pass or fail recorded next to them.
2. Every rung has a null that must refuse; a rung without a working refusal is not green.
3. Verdict vocabulary everywhere: CONTAINED / UNCONTAINED / REFUSED (code), CONSISTENT / WOUND / DOF-OPEN (structures), BALANCED / RESIDUAL (circuits) — same three-verdict shape, domain costume.
4. Instruments never mind: geometry kernel, SPICE, compilers — measure with them, never believe them without the receipt.
5. Client-facing later: leads not verdicts, bare outputs, ledger internal.
6. Sequence within a segment is strict; sequence *between* E1/E2/E3 is not — park and switch freely. E0 gates everything.
